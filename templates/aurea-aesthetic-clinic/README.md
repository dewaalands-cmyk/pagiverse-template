# Auréa Aesthetic Clinic

Pagiverse Standard 1, vanilla HTML/CSS/JS, five Indonesian pages.

## Demo content
All business identity, addresses, phone numbers, prices and doctor profiles are fictional examples. Generated photographs depict fictional settings and people. Replace with verified business data before customer use. No fabricated credentials or patient testimonials are included.

## Factory reuse
Website Blank v1 manifest structure, binding, mobile navigation and ready/config/applied handshake; hardened runtime adapted from the existing Senja Atelier template. Custom Auréa page composition, service filtering, bounded arrays, FAQ and reservation presentation.

## Reservation integration
Native form validation. Cancel the bubbling pagiverse:form-submit event to let Core own processing, or supply PAGIVERSE_CORE.submitForm. Without a Core handler the form shows demo status and an explicit WhatsApp handoff; it does not claim to save or confirm a booking. No backend or secrets are included.

## Image prompts
Built-in ImageGen: warm cream/espresso boutique clinic architectural interior; clothed Indonesian client receiving gentle facial care; fictional female doctor in ivory coat. Outputs optimized into assets/images.

Theme tokens are protected to preserve contrast and the approved palette. All configured copy is rendered as plain text.
