# BRUTAL BUN

Pagiverse Standard 1 migration of the approved one-page BRUTAL BUN restaurant concept. Template ID: `brutal-bun-burger-001`. Catalog price: Rp1.450.000.

Reuses Website Blank v1's schema loading, binding, section visibility, protected theme, and same-origin ready/config/applied protocol. Custom components preserve the punk poster hero, organic food mask, filterable menu, and illustrated location map. Configuration supports both flat dotted Studio keys and nested objects. Copy is rendered as plain text; URLs are restricted to HTTPS or approved local/raster image sources.

Business details, burger prices, hours, and Kemang location are demo data. The menu is a catalog, without cart, checkout, or ordering. Replace demo location disclaimers when entering real business data. The map is decorative; the Maps button opens the configured external URL.

Design: protected wine/red/blush/black/white palette, Anton condensed display font (SIL OFL included), 15px controls and 12px menu cards. Hero and product photos are editable with focal points. Menu supports 0–18 items and three fixed categories; hours support 1–7 rows. The manifesto is optional; hero/menu/location/footer remain required.

Assets: hero generated for this project using built-in ImageGen; menu photos from Unsplash, used as illustrative demo photography. Original sources: `photo-1568901346375-23c9450c58cd`, `photo-1606755962773-d324e0a13086`, `photo-1520072959219-c595dc870360`. Generated hero prompt: photorealistic double smash cheeseburger with sesame brioche, melted cheese, charred beef, pickles and red sauce; direct flash; solid #260212 background; full burger visible; no plate, props, text or logos. Raster files optimized to WebP.
