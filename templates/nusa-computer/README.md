# NUSA Computer

Template ID: nusa-computer-001. Galeri toko komputer berbahasa Indonesia, IDR, kanvas putih, radius28px, kontrol biru kecil tanpa bayangan.

102 field editor dan lima koleksi berbatas: produk0-24, kategori0-8, showcase0-6, keunggulan0-6, FAQ0-12. Gunakan template.json untuk identitas, gambar/focal/crop, navigasi, konten, serta kontak WhatsApp.

## Kompatibilitas

Manifest, katalog, binding dan protokol iframe mengikuti Pagiverse Standard1. Keranjang, PCbuilder dan ringkasan pesanan adalah ekstensi khusus yang diminta pengguna; bukan fitur commerce Core Standard1 dan bukan klaim kepatuhan ketat Standard1. Tidak ada checkout, pembayaran, atau penyimpanan pesanan di server.

Nomor WhatsApp default kosong. Pelanggan dapat menyalin/mengunduh TXT. Sesudah contact.whatsapp diatur valid, tautan wa.me dibuat saat pengunjung memilih melanjutkan. Pengunjung tetap mengirim pesan sendiri.

Kecocokan PC hanya pemeriksaan dasar. Metadata hardware dilindungi; mengubah nama/spec/ID hardware mengeluarkannya dari builder. BIOS, konektor, pendinginan dan ruang fisik tetap ditinjau toko. Harga dan produk NUSA adalah data contoh.

## Portabilitas

Semua dependensi runtime berada di assets/runtime, CSS tambahan di assets/, sehingga ikut disalin oleh sinkronisasi Studio. Infrastruktur binding dan pesan diadaptasi dari factory/website-blank-v1; komposisi galeri serta ekstensi commerce khususNUSA.

## QA

Lulus Chrome360/768/1280/1440, konfigurasi iframe berulang, fieldmaksimum, koleksikosong/maksimum, semua bagianopsionaldisembunyikan, logo/foto/focal/crop, URL tidakaman, plain-textXSS, keyboarddialog, reducedmotion, keranjangpersisten dan validasiRAM. Bukti eksternal tersimpan di direktoriQA sesi; tidak dipublikasikan sebagaiaset.

Foto galeri menggunakan built-in image_gen. Sumber foto komponen tercatat di ASSET-SOURCES.json. Ikon Phosphor2.1.1 (MIT), aset lokal. Font SFPro menggunakan fallback sistem ketika tidak tersedia.
