# Sela Studio

Template portfolio studio desain kreatif berbahasa Indonesia. Pagiverse Standard 1, ID sela-studio-design-001, kategori agency.

## Menjalankan

Sajikan folder ini dengan server HTTP statis dan buka index.html. Tidak membutuhkan build atau library runtime.

## Desain

Terinspirasi ritme editorial dan kolase bergerak Studio.Design (https://studio.design/), dengan interpretasi dan karya orisinal Sela Studio. Sumber token pengguna dipertahankan di assets/reference/ dan dipakai melalui assets/tokens.css. Inter dan Inter Tight disimpan lokal, dengan lisensi SIL Open Font License di assets/fonts/. UI memakai #eeeeee, #ffffff, #222222, #333333, #555555; gambar 4px, tombol 8px, dialog 8px. Tema dan font dilindungi untuk menjaga kontras.

## Konten dan interaksi

Semua data bisnis adalah contoh yang dapat diganti. Galeri, layanan, dan proses memakai koleksi berbatas. Filter karya, dialog proyek, menu mobile, pause/resume motion, dan preferensi reduced-motion didukung. Editor menerima pesan pagiverse:config dari parent yang sama origin dan mengirim ready/applied. Konfigurasi setara mempertahankan node/fokus/disclosure. Teks pengguna dirender sebagai plain text.

## Brief demo

Formulir memvalidasi input dan membuat ringkasan TXT yang dapat diunduh di browser. Tidak mengirim email, menyimpan ke database, atau menghubungi alamat demo. Hubungkan pengiriman bisnis melalui Pagiverse Core sebelum digunakan secara operasional. Alamat hello@sela.example sengaja bukan tujuan bisnis.

## Aset

Empat karya konsep orisinal dibuat dengan built-in image_gen; prompt lengkap, lokasi asli, dan notice demo: assets/ASSET-PROVENANCE.md. Aset final: assets/images/ruang-rasa.webp, forma.webp, titik-temu.webp, antara.webp. Thumbnail adalah tangkapan template aktual.
