# Website Blank v1

Scaffold modular untuk membuat template Pagiverse Standard 1 dengan vanilla HTML, CSS, dan JavaScript.

Modul dasar yang tersedia:

- navigasi responsif;
- hero dengan gambar editable;
- layanan berbasis array;
- social proof/testimonial berbasis array;
- CTA dan footer;
- live-preview handshake `pagiverse:ready`, `pagiverse:config`, dan `pagiverse:applied`.

Salin folder ini ke `templates/<template-name>/`, ganti identitas dan kontennya, lalu validasi terhadap Pagiverse Standard 1. Infrastruktur dapat dipakai ulang, tetapi arah visual harus dibuat khusus untuk setiap bisnis.
